Quantumult X 自定义资源解析器

让 QX 读懂别家的订阅
节点、分流、重写一次转好

V2RayN、Clash、Surge、Loon、Shadowrocket、SIP008、Hysteria2 的订阅与规则，交给它统一翻译成 Quantumult X 的写法。转换规则可以按关键词筛、按正则改、按策略组分配，全都写在链接的参数里。

resource_parser_url = https://qx.tatalvpai.vip/Scripts/resource-parser.js
查看脚本 GitHub 仓库

安装

三步装好，之后所有资源引用都能用上解析器。

1

写进配置文件

在 QX 配置的 [general] 段落里加一行 resource_parser_url = …，地址见上方复制按钮。

2

勾上「使用解析器」

进「资源引用」，编辑要用的节点订阅、分流、重写，把「使用解析器」打开。

3

刷新资源

下拉刷新引用；若提示「没有自定义解析器」，长按首页右下角图标点左侧刷新，再彻底退出 App 重进。

带参数怎么用
// 参数跟在订阅地址的 # 后面，多个用 & 连接
https://你的订阅地址#emoji=1&udp=1&in=香港+台湾&rename=旧名@新名

// 本地 / iCloud 里的规则文件同样支持（build 951 起），路径上的参数优先
// 特殊字符先 URL-Encode：+ → %2B，空格 → %20，@ → %40，& → %26，, → %2C

sortx=1 / -1按订阅分组（tag）正序或倒序
checkurl=xxx指定 server_check_url
host=xxx改已有 host；想新增 host 就在结尾加 ☠️

参数作用
in / out按关键词保留或删除 rewrite、filter 条目
regex / regout同上，用正则匹配
inhn=xxx按 hostname 保留
outhn=xxx按 hostname 删除
policy=xxx指定策略组；解析 Surge rule-set 时用它生成策略组
pset=正则@策略同一份规则里不同关键词分别给不同策略组，多组用 +

参数作用
ntf=0 / 1关或开解析通知，重写与分流默认开、节点默认关

$index0-8占位符：节点序号，9 种样式，从 1 到 𝟷
$emoji1/2占位符：节点名里的地区旗帜
$tag占位符：订阅的 tag，后面可跟数字指定花漾样式

常见问题

装不上、转不对，多半是下面几种情况。

提示「没有自定义解析器」怎么办？

说明 QX 还没拉到脚本。确认配置文件那行写的是 resource_parser_url = https://qx.tatalvpai.vip/Scripts/resource-parser.js，然后长按首页右下角图标，点左侧的刷新按钮更新资源，再从后台彻底退出 App 重进，直到资源页出现解析器说明。

节点转出来是空的，或者少了几条？

先在链接后加 cnt=1，通知里会告诉你最终条目数；再加 type=nodes 强制按节点解析。如果通知里写明「不支持的节点」，那是协议本身 QX 还不支持（例如部分传输方式的 VLESS、gRPC、mKCP）。

分流规则全都丢了？

检查是不是给规则资源勾了错误的类型：rule-set 想转成分流需要 dst=filter；如果是 module，那本身该走重写。另外 in= 写错关键词会把规则全筛掉，加 hide=0 可以把被筛掉的条目以注释形式留住，方便对照。

订阅更新后策略组名字变成 Minimax 了？

解析 Surge rule-set 时若规则本身没带策略，解析器会给一个默认策略组名 Minimax。想用别的名字，加 policy=你的策略组。

参数里的 + & @ 老是出错？

这三个字符在 URL 里有特殊含义，写进参数前要编码：+ → %2B，空格 → %20，& → %26，@ → %40，, → %2C。中文关键词直接写没问题，但建议也一并编码。

能不能只转某个机场的部分节点？

可以。用 in=香港+台湾 按名字保留，或 regex=iplc 按线路特征保留，再配合 rename= 统一改名。sort=1 可以让节点按名字排好。
